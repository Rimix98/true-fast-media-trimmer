# Медиа Обрезчик (Fast Media Trimmer)

Быстрый настольный видео- и аудиоредактор на Python (PySide6 + FFmpeg) с аппаратным ускорением **OpenGL / GPU**, мульти-отрезковым таймлайном, микшером звуковых дорожек в дБ и мгновенной обрезкой без перекодирования.


## Основные возможности

* **Мульти-отрезковый таймлайн:** добавление любого количества отрезков по правому клику (ПКМ), перетаскивание отрезков целиком, автоматический переход между отрезками при проигрывании и точность до **0.01 секунды**.
* **Два режима экспорта:**
  * *Мгновенный (Stream Copy)* — вырезает за 1–2 секунды без потери качества.
  * *Точный (GPU / CPU)* — перекодирование до доли секунды через видеокарту (`NVENC` / `AMF` / `QSV`) со склейкой всех отрезков в один файл или сохранением по отдельности.
* **Микшер звуковых дорожек:** регулировка громкости каждой дорожки от `-∞ dB` до `+24.0 dB`, кнопка **Мут (Mute)** и объединение нескольких дорожек в одну.
* **Плавный скраббинг и предпросмотр:** накопительный кэш опорных кадров с приоритетной зоной `±10 сек` вокруг курсора, переключение разрешения предпросмотра и меню скриншотов по ПКМ (копирование в буфер обмена или сохранение в файл).
* **Интеграция в Windows:** добавление в контекстное меню «Открыть с помощью», поддержка Drag & Drop, тёмная/светлая тема с выбором акцентного цвета и автообновление через GitHub.


## Установка и запуск

1. Установите **Python 3.10+** (при установке отметьте *Add Python to PATH*).
2. Скачайте репозиторий или только файл `fast-media-trimmer.py`.
3. Запустите программу двойным кликом или через терминал:
   ```bash
   python fast-media-trimmer.py
   ```
   *(Необходимые библиотеки `PySide6`, `numpy`, `imageio-ffmpeg` и недостающие модули установите сами через pip install -r requirements.txt).*


## Горячие клавиши

| Клавиша | Действие |
| :--- | :--- |
| `Space` | Воспроизведение / Пауза |
| `←` / `→` | Шаг назад / вперёд на **0.01 сек** |
| `Shift + ←` / `Shift + →` | Шаг назад / вперёд на **1.00 сек** |
| `Ctrl + Колёсико мыши` | Масштабирование таймлайна под курсором |
| `F11` | Полноэкранный режим |
| `ПКМ по шкале` | Добавить или удалить отрезок обрезки |
| `ПКМ по видео` | Скопировать кадр в буфер обмена или сохранить скриншот |
