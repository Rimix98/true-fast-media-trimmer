# Истинный Быстрый Медиа Обрезчик (True Fast Media Trimmer)

Быстрый настольный видео и аудиоредактор на Python (PySide6 + FFmpeg) с аппаратным ускорением **OpenGL / GPU**, мульти-отрезковым таймлайном, микшером звуковых дорожек в дБ и мгновенной обрезкой без перекодирования.

## Основные возможности

* **Мульти-отрезковый таймлайн:** добавление любого количества отрезков по правому клику (ПКМ), перетаскивание отрезков целиком, автоматический переход между отрезками при проигрывании и точность до **0.01 секунды**.
* **Два режима экспорта:**
  * *Мгновенный (Stream Copy)* — вырезает за 1–2 секунды без потери качества.
  * *Точный (GPU / CPU)* — перекодирование до доли секунды через видеокарту (`NVENC` / `AMF` / `QSV`) со склейкой всех отрезков в один файл или сохранением по отдельности.
* **Микшер звуковых дорожек:** регулировка громкости каждой дорожки от `-∞ dB` до `+24.0 dB`, кнопка **Мут (Mute)** и объединение нескольких дорожек в одну.
* **Плавный скраббинг и предпросмотр:** накопительный кэш опорных кадров с приоритетной зоной `±10 сек` вокруг курсора, переключение разрешения предпросмотра и меню скриншотов по ПКМ (копирование в буфер обмена или сохранение в файл).
* **Интеграция в Windows:** добавление в контекстное меню «Открыть с помощью», поддержка Drag & Drop, тёмная/светлая тема с выбором акцентного цвета и автообновление через GitHub.

## Установка и запуск

1. Установите **Python 3.10+** (при установке отметьте *Add Python to PATH*).
2. Скачайте репозиторий.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите программу двойным кликом или через терминал:
   ```bash
   python main.py
   ```
   *(Необходимые библиотеки `PySide6`, `numpy`, `imageio-ffmpeg`.*


## Структура проекта

Код разнесён по небольшим модулям внутри пакета `trimmer/`, точка входа — `main.py`:

```
main.py                    # запуск приложения (python main.py)
trimmer/
├── app.py                 # создание QApplication и главного окна
├── constants.py           # версия, пути, форматы, границы дБ
├── settings.py            # настройки по умолчанию, палитры, загрузка/сохранение
├── system.py              # тема заголовка Windows, дБ-подписи, выбор кодировщика
├── context_menu.py        # интеграция в меню «Открыть с помощью» (Windows)
├── updater.py             # проверка обновлений на GitHub
├── frame_worker.py        # фоновое извлечение кадров (FFmpeg → QImage)
├── audio_stream.py        # поток PCM-звука дорожки с усилением
├── ffmpeg_thread.py       # фоновый запуск FFMpeg с прогрессом и ETA
├── seek_slider.py         # ползунок перемотки
├── waveform.py            # виджет аудиоволны
├── trim_slider.py         # мульти-отрезковый ползунок обрезки
├── video_view.py          # видеовиджет с предпросмотром
├── progress_dialog.py     # диалог прогресс-бара
├── tracks_dialog.py       # микшер звуковых дорожек
├── export_dialog.py       # настройки экспорта
├── settings_dialog.py     # настройки программы
├── window_ui.py           # миксин: интерфейс, тема, зум, drag & drop
├── window_controls.py     # миксин: хоткеи, диалоги, микшер, прогресс
├── window_files.py        # миксин: открытие файлов, кадры, скриншоты
├── window_playback.py     # миксин: воспроизведение, перемотка, метки
├── window_export.py       # миксин: пайплайн экспорта
└── main_window.py         # класс MediaTrimmerWindow (сборка миксинов)
```

## Горячие клавиши

| Клавиша | Действие |
| :--- | :--- |
| `Space` | Воспроизведение / Пауза |
| `←` / `→` | Шаг назад / вперёд на **0.01 сек** |
| `Shift + ←` / `Shift + →` | Шаг назад / вперёд на **1.00 сек** |
| `Ctrl + Колёсико мыши` | Масштабирование таймлайна под курсором |
| `F11` | Полноэкранный режим |
| `ПКМ по шкале` | Добавить или удалить отрезок обрезки |
| `ПКМ по видео` | Скопировать кадр в буфер обмена или сохранить скриншот |
